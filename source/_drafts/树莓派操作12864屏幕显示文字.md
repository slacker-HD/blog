本文介绍如何在树莓派上通过Python驱动0.96寸SSD1306协议屏幕，实现系统信息的文字显示，包括时间、IP地址、CPU使用率与温度、内存、交换分区等信息，让它变成一块实时运行状态屏。其它诸如ssd1306, ssd1325, ssd1331, sh1106等协议，或者12832的屏幕的代码也是类似的，只是更换驱动即可。

## 1. 硬件准备

### 1.1 所需硬件

- 树莓派（所有型号应该都是一样的）
- IIC接口的0.96寸12864 OLED屏幕（SSD1306协议）
- 杜邦线若干

### 1.2 硬件连接

12864 OLED屏幕通过IIC协议与树莓派通信，需连接4根线：

- VCC：接树莓派3.3V引脚
- GND：接树莓派GND引脚
- SDA：接树莓派GPIO2（SDA1）引脚
- SCL：接树莓派GPIO3（SCL1）引脚

### 1.3 启用IIC接口

打开终端，输入以下命令进入配置界面：

```bash
sudo raspi-config
```

依次选择 Interface Options → I2C → Yes 启用 IIC 接口。

## 2. 关键代码实现

### 2.1 安装依赖库

驱动12864屏幕需用到luma.oled，并结合Pillow做文字绘制，统计CPU使用率还需要psutil，安装命令如下：

```bash
# 安装luma.oled库
pip3 install luma.oled

# 安装Pillow库（绘制文字）
pip3 install pillow

# 安装psutil库（获取CPU使用率）
pip3 install psutil
```

### 2.2 代码实现

#### 2.2.1 初始化硬件与画布

通过`i2c`函数初始化I2C通信接口，指定通信端口为`port=1`（树莓派常用I2C端口），设备地址为`0x3C`（屏幕的I2C地址，需与实际硬件匹配）。基于初始化的I2C接口，使用`ssd1306`驱动创建OLED设备实例（注释提示可根据屏幕型号替换为ssd1325、ssd1331、sh1106等其他协议驱动）：

```python
serial = i2c(port=1, address=0x3C)
# 初始化设备，这里改ssd1306, ssd1325, ssd1331, sh1106
device = ssd1306(serial)
```

之后用`canvas(device) as draw`包住绘制代码，luma会自动清屏并把绘制结果刷新到屏幕上，无需手动清理上一帧。先画一个边框，再用`draw.text`按坐标写入文字：

```python
with canvas(device) as draw:
    draw.rectangle(device.bounding_box, outline="white", fill="black")
    draw.text((5, 1), "时间:" + time.strftime('%H:%M %m-%d', time.localtime()), fill="white", font=font)
```

屏幕只有128x64，12号字体每行占约12px，所以各行坐标按`y = 1, 13, 25, 37, 49`往下排，正好放下五行文字。

#### 2.2.2 获取系统信息

获取各项状态的小函数用了几种简单方法：IP地址通过UDP连接探测得到本机实际出口IP；CPU温度直接读`vcgencmd measure_temp`命令输出；CPU使用率用psutil；内存和交换分区解析`free -m`的输出。注意`free -m`第一行是标题，第二行是内存，第三行才是交换分区，所以解析时行号要区分开：

```python
def getCPUtemperature():
    res = os.popen('vcgencmd measure_temp').readline()
    temp = res.replace("temp=", "").replace("'C\n", "")
    return temp

def getCPUuse():
    cpu_usage_percent = psutil.cpu_percent(interval=1)
    return str(cpu_usage_percent)

def getRamInfo():
    p = os.popen('free -m')
    i = 0
    while 1:
        i = i + 1
        line = p.readline()
        if i == 2:
            RAM_stats = line.split()[1:4]
            break
    return str(RAM_stats[1]) + "/" + str(RAM_stats[0]) + "MB"

def getSwapInfo():
    p = os.popen('free -m')
    i = 0
    while 1:
        i = i + 1
        line = p.readline()
        if i == 3:
            SWAP_stats = line.split()[1:4]
            break
    return str(SWAP_stats[1]) + "/" + str(SWAP_stats[0]) + "MB"
```

#### 2.2.3 中文字体处理

OLED屏幕本身不带中文字库，想显示"时间""内存"这类中文就得自己加载TTF字体文件。`ImageFont.truetype('字体路径', 字号)`指定字体，这里用的文泉驿字体`wqy.ttf`：

```python
font = ImageFont.truetype('/home/pi/python/wqy.ttf', 12)
```

如果不显示中文，也可以直接不指定`font`参数，用默认字体显示英文信息。

### 2.3 完整代码

完整代码如下：

```python
# -*- coding: utf-8 -*-
from luma.core.interface.serial import i2c  #, spi
from luma.core.render import canvas
from luma.oled.device import ssd1306  #, ssd1325, ssd1331, sh1106
from time import sleep
from PIL import ImageFont
import socket
import os
import time
import psutil

# 查询本机IP地址
def get_host_ip():
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        s.connect(('8.8.8.8', 80))
        ip = s.getsockname()[0]
    finally:
        s.close()
    return ip

# 获取CPU温度
def getCPUtemperature():
    res = os.popen('vcgencmd measure_temp').readline()
    temp = res.replace("temp=", "").replace("'C\n", "")
    return temp

# 获取CPU使用率
def getCPUuse():
    cpu_usage_percent = psutil.cpu_percent(interval=1)
    return str(cpu_usage_percent)

# 获取内存使用情况
def getRamInfo():
    p = os.popen('free -m')
    i = 0
    while 1:
        i = i + 1
        line = p.readline()
        if i == 2:
            RAM_stats = line.split()[1:4]
            break
    return str(RAM_stats[1]) + "/" + str(RAM_stats[0]) + "MB"

# 获取交换分区信息
def getSwapInfo():
    p = os.popen('free -m')
    i = 0
    while 1:
        i = i + 1
        line = p.readline()
        if i == 3:
            SWAP_stats = line.split()[1:4]
            break
    return str(SWAP_stats[1]) + "/" + str(SWAP_stats[0]) + "MB"

def main():
    __version__ = 1.0
    # 初始化端口
    serial = i2c(port=1, address=0x3C)
    # 初始化设备，这里改ssd1306, ssd1325, ssd1331, sh1106
    device = ssd1306(serial)
    print("当前版本:", __version__)
    # 加载中文字体，需要提前放到该路径
    font = ImageFont.truetype('/home/pi/python/msyh.ttc', 12)
    while (True):
        with canvas(device) as draw:
            draw.rectangle(device.bounding_box, outline="white", fill="black")
            draw.text((5, 1), "时间:" + time.strftime('%H:%M %m-%d', time.localtime()), fill="white", font=font)
            draw.text((5, 13), "IP地址:" + get_host_ip(), fill="white", font=font)
            draw.text((5, 25), "CPU:" + getCPUuse() + "%温度:" + getCPUtemperature() + "C", fill="white", font=font)
            draw.text((5, 37), "内存:" + getRamInfo(), fill="white", font=font)
            draw.text((5, 49), "交换区:" + getSwapInfo(), fill="white", font=font)
        sleep(5)

if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        pass
```

在终端中执行以下命令运行程序，屏幕每5秒刷新一次系统信息，按Ctrl+C可停止：

```bash
python3 oled_text.py
```

## 3. 运行效果

128x64的屏幕上自上而下显示五行信息：第一行是时间和日期、第二行是IP地址、第三行是CPU使用率和温度、第四行是内存占用、第五行是交换分区占用。外圈有一个白色边框，看起来比较规整。这个脚本稍加改造就能接上魔镜、监控面板之类的项目，比如把刷新间隔调大、加入磁盘占用显示，或换成远程主机的状态等。
